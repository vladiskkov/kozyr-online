# Козир — дурень онлайн

Онлайн-гра в дурака: **підкидний** і **переводний**, до 4 гравців, боти трьох рівнів складності, вхід через Google. Є режим **махлювання**: класти неправильні карти можна, але якщо суперник помітить і натисне «Викрити», шахрай забирає весь стіл.

## Можливості

- Гра з ботами (1–3 суперники) — рівні: легкий, середній, складний.
- Кімнати для друзів: код із 5 символів і посилання-запрошення, вільні місця можна заповнити ботами.
- Режими підкидання для 3–4 гравців: **по черзі** (спершу той, хто ходив, далі за годинниковою стрілкою) або **хто встиг**.
- Махлювання з викриттям: шахрай забирає стіл, помилкове звинувачення — штрафна карта, одне викриття на відбій.
- Сервер вирішує все: карти суперників ніколи не потрапляють у браузер.
- 30 секунд на хід; якщо гравець вийшов — його місце займає бот.

## Технології

Node.js 20+, Express, Socket.IO, Google Identity Services. Без бази даних і без збірки фронтенду.

```
server/
  index.js   — HTTP, CSP, Socket.IO
  auth.js    — перевірка Google ID token, сесії в підписаному cookie
  rooms.js   — кімнати, таймери, планувальник ботів
  game.js    — рушій правил
  bots.js    — штучний інтелект ботів
public/      — клієнт (HTML/CSS/JS), rules.js спільний із сервером
test/        — симуляції тисяч партій ботами
```

## Локальний запуск

```bash
npm install
npm test
GOOGLE_CLIENT_ID=ваш-id.apps.googleusercontent.com npm start
# http://localhost:3000
```

Без `GOOGLE_CLIENT_ID` працює лише гостьовий вхід.

## Змінні оточення

| Змінна | Опис |
|---|---|
| `GOOGLE_CLIENT_ID` | OAuth Client ID (Web) з Google Cloud Console |
| `SESSION_SECRET` | Випадковий рядок для підпису cookie (Render генерує сам) |
| `ALLOW_GUESTS` | `false`, щоб вимкнути вхід без Google |
| `PORT` | Порт (Render задає сам) |

## Деплой на Render (безкоштовно)

1. Зареєструйтесь на [render.com](https://render.com) через GitHub.
2. **New → Blueprint**, оберіть репозиторій `kozyr-online` — Render прочитає `render.yaml`.
3. Введіть `GOOGLE_CLIENT_ID`, натисніть **Apply**.
4. Додайте адресу сайту (`https://kozyr-online.onrender.com`) в **Authorized JavaScript origins** вашого Google OAuth-клієнта.

Безкоштовний сервер засинає після 15 хвилин без відвідувачів і прокидається приблизно за хвилину. Кімнати живуть у пам'яті й зникають після перезапуску.
